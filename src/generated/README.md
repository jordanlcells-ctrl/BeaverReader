# Generated native env

- **`env.native.ts`** — created by `npm run env:gen` (see `scripts/write-env-module.js`) from the project root **`.env`**. This file is **gitignored**; do not commit real keys.
- **`env.native.example.ts`** — safe placeholder committed for reference only.

After cloning: copy `.env.example` to `.env`, fill in Supabase values, then run `npm run env:gen` or `npm install`.
