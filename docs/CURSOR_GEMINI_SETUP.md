# Open Cursor Models / Add Gemini in Cursor

## How to get to Models in Cursor

1. **Click the gear icon** (⚙️) in the **bottom-left** of the Cursor window.
2. In the menu that opens, click **"Cursor Settings"** (or **"Settings"** if that’s what you see).
3. In the **left sidebar** of the settings screen, look for **"Models"** and click it.

   If you don’t see "Models":
   - Scroll the left sidebar up/down.
   - Look for **"Features"** or **"Beta"** and see if "Custom models" or "Models" is under there.
   - Use the **search box** at the top of settings and search for **"Models"** or **"API key"**.

4. On the **Models** page you can add your **Google API key** so Gemini appears in the model list.  
   You may see an **"Add API key"** or **"Add provider"** (e.g. Google) where you paste your key.

---

## Alternative: Command Palette

1. Press **`Ctrl + Shift + P`** to open the Command Palette.
2. Type **`Cursor Settings`** or **`Models`**.
3. Choose the command that opens Cursor Settings or Models (e.g. **"Cursor: Open Cursor Settings"** or **"Preferences: Open Cursor Settings"**).
4. In the left sidebar, open **Models** and add your Google API key there.

---

## If you still don’t see Models

- **Update Cursor** to the latest version (Help → Check for Updates).
- The **Models** section might be under a **Cursor** or **Account** area in the left sidebar.
- On some versions, **API keys** are under **Cursor Settings → General** or **Cursor Settings → Account**.

Once you’re on the Models (or API keys) page, paste your Google AI Studio API key for the Google/Gemini provider and save.
